# 问卷星移动答题页

适配 `/vm/<id>.aspx` 的 `.field[topic][type]` 布局，状态为 experimental。

- 识别单选（type=3）、多选（type=4）、单行填空（type=1）、简答（type=2）。考试子域或带 ceshi 标记的题目按知识题处理；普通问卷意图未确认，保持手动作答。
- 姓名、部门等明确的基本信息标签与矩阵信息栏不进入模型；不读取输入值、脚本、隐藏答案或分数配置。
- 同页多题使用扩展自己的题目游标，扫描只返回当前题。悬浮面板提供题目选择和下一题；不隐藏原网页其他题目。游标存在 form 的 data-autoffer-wjx-topic 属性中，脚本重复注入后保持一致。
- 客观题点击真实选项标签，核对隐藏 input 的 checked 与 jqchecked 状态一致后切换本地游标。支持取消、旧题校验、禁用控件和遮挡检查。
- 填空、简答展示参考答案，用户手动填写后在悬浮面板切换下一题。插件不点击 ctlNext、提交或交卷按钮。
- 当前不覆盖桌面 /jq/ 布局、分页导航、矩阵、排序、量表、纯图片题干、验证码或 iframe。题目表最多读取前 100 个可见块，超过此数量不代表整卷识别完成。
