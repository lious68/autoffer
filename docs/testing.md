# 验证与验收

## 自动验证

```sh
npm run check
```

包含 TypeScript、离线回归、Prettier 和生产构建。不调用真实供应商，不需要 Key。覆盖模板匹配、代码缩进、隐藏旧题、模型协议、Key 隔离、权限绑定、后台重建后的同文档授权，以及自动会话的切题、取消、缓存和停止行为。

## 浏览器验收

1. 重新加载 `dist/`，点击工具栏图标，应打开紧凑卡片弹窗。确认 AstraFlow 只需填写 Key。
2. 选择模型渠道、保存 Key。对新 API 网站仅申请对应域名权限；拒绝授权不应保存配置。
3. 牛客测试题页面点击「开始」，关闭弹窗，已开始的题目会话继续解析；勾选自动选答时选中并进入下一题。
4. 检查解析和选答期间外圈转动，结果显示答案、模型置信度及计数；重复 DOM 更新不重复扣费。
5. 手动翻题、哈希变化、关闭配置窗口不应出现要求重新识别的流程。旧请求迟到不得填入新题。
6. 隐藏悬浮球后界面消失，处理继续；从配置窗口显示或暂停。页面隐藏/切换标签时保持运行，手动停止后恢复可见不应自动重启。
7. 连续模式超过 5 题仍继续。最终模型低置信度不修改选项，直接下一题；最后一题无论选答还是跳过，都不点击提交。
8. 未知置信度待复核；错误继续观察新题。网络/超时/页面未稳定按 5/15/45 秒最多重试 3 次，写入失败不盲目重试。
9. 使用真实全屏测试球的位置；进入/退出 fullscreen 后仍可操作。不改变考试监测规则。
10. 重启后台 service worker 后，同文档消息仍授权；整页刷新更换 documentId 后需重新启用。保存新渠道配置应暂停旧会话并清空答案缓存。

## AstraFlow 卡片

- 只显示 Key 输入、只读模型名和启用开关，无地址/模型输入、无图片开关、无保存按钮。
- 固定地址为 `https://api.modelverse.cn/v1`，模型为 `deepseek-v4.1-flash`，Key 不跨地址复用。
- 修改 Key 后保持关闭，手动启用前不申请权限或调用模型；快速输入、关窗、重开仍保留最后草稿和单处验证结果。

- AstraFlow 连通性测试使用 `thinking: { type: "disabled" }` 和 `max_tokens: 64`，要求完成的正文；思考内容不当作最终答案。截断、拒答、空正文分别报错，不回显上游内容，不重试。正式答题参数不受影响。

## Key 确认交互

Jev 固定 TypeSafe 官方渠道，AstraFlow 固定 ModelVerse 地址和模型。两张卡片均只有 Key 输入框，右侧「确认」保存并验证成功后启用；无渠道、模型等其他输入或删除 Key 按钮。测试覆盖确认时等待最后一次保存、重复点击仅请求一次、回车确认、验证期间关闭开关取消。
