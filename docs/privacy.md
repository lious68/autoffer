# 隐私说明

本项目没有账号系统、项目服务器或分析埋点。

固定渠道 TypeSafe、AstraFlow（`api.modelverse.cn`）和 Vercel 的 API 网站权限随扩展声明；下文的按需网站授权流程适用于其余自定义渠道。网页识题仍使用 `activeTab`，不会因此获得测评网站的持久访问权限。

## 数据流

| 操作         | 读取                                 | 保存                        | 外发                                               |
| ------------ | ------------------------------------ | --------------------------- | -------------------------------------------------- |
| 扫描页面     | 模板限定范围内的可见题目、材料、选项 | 扩展内存快照                | 无                                                 |
| 获取建议     | 所选题目                             | 内存中的建议结果            | 题干、材料、选项发往所选渠道，见下文               |
| 保存设置     | 用户输入的 Key、模型 ID、提醒阈值    | 本机 `chrome.storage.local` | 仅本地自动保存，不验证、不外发                     |
| 真实模型请求 | 所选渠道的本机 Key                   | 无新增凭据副本              | Key 只发送给所属固定渠道或已保存自定义地址用于鉴权 |

TypeSafe 官方直连 `api.typesafe.ai`；Vercel 连接 `ai-gateway.vercel.sh`，转交 TypeSafe；Jev Agent 是独立第三方，连接 `jev-agent.com` 并转交 TypeSafe；OpenRouter 连接 `openrouter.ai`，转交所选模型供应商；自定义接口连接用户保存的 HTTPS Base URL。渠道 Key 分开保存，自定义 Key 再按规范化完整 Base URL 隔离，不跨地址复用。尚不合法的地址使用独立草稿范围保存 Key；修正地址后需重新填写，不把不确定地址的 Key 自动带到新地址。启用双模型时，纯文字客观题优先 Jev；缺失、失败或低确定度后，会将同一题交给已配置的通用模型一次，可能产生两次用量。图片和主观题直接使用通用模型。

修改模型配置时自动保存到本机，接受未填完或格式错误的草稿；自动保存不会申请网站权限或调用模型。仅在用户手动打开模型开关时申请对应 API 网站的浏览器可选访问权限；启用阶段才校验，拒绝授权或格式错误时保留草稿并告警。格式和权限通过后，后台向对应地址发送一次最小模型请求（Chat：Reply OK.；Jev：一个 Noul 判断），仅包含合成测试信息和用于鉴权的 Key，不包含网页题目或截图。手动启用可能产生一次少量模型用量；编辑、自动保存、切换界面或读取配置都不会调用。验证超时为 15 秒，不重试、不切换供应商，成功后才启用。关闭会中止验证和当前会话，保留配置及 Key。网页内工具只得到题目和建议，不得到凭据；启用后自动请求每道新题，自动选答模式持续到当前题型末题；最终低置信度跳过，遇到其他复核条件或最终模型异常暂停，不自动提交题型或交卷。页面隐藏不会停止识别；悬浮球仅展示进度和日志，控制在扩展卡片。

手动开始才运行；暂停保留本轮，手动结束后生成本地报告，记录题干、建议、模型路线、状态、确定度与耗时。报告存在扩展 session 存储（浏览器重启清除），结束后自动下载 Markdown 到浏览器默认下载文件夹，不上传。最多保留最近 300 题并标注截断。

启用通用模型的视觉选项后，后台通过 activeTab 临时截取可见页；只把平台模板定位的题目图像区域裁剪发往通用模型。完整截图仅短暂存在后台内存，不保存、上传或写入日志；图片源 URL 不发送。未加载、遮挡、不完整可见或几何位置变化时停止，不发送整个页面作为回退。

不主动读取 Cookie、简历、表单中用户已填内容或完整浏览记录。不发送网页 URL；UI 展示来源时移除查询参数和 fragment。题目文本本身也可能包含敏感信息，获取建议前请核对识别结果。

Chrome 本地扩展存储不是系统密钥链，也没有由本扩展加密。本机具有相应访问能力的程序仍可能读取它。可在设置中替换 Key；卸载扩展会清除它的本地存储。

供应商如何保留和处理请求，以所选渠道及下游服务商的政策为准，包括 [TypeSafe 条款](https://docs.typesafe.ai/legal)、[Vercel 隐私政策](https://vercel.com/legal/privacy-policy)、[Jev Agent 隐私政策](https://jev-agent.com/privacy)、[OpenRouter 隐私政策](https://openrouter.ai/privacy)。自定义接口由其运营者处理。没有项目后端不等于模型推理离线。

报告下载由后台使用 Chrome downloads API 完成，使用固定文件名前缀与 saveAs=false。只按本轮下载 ID 查询完成状态，不读取其他下载记录；关闭卡片不会取消文件下载。下载失败时报告仍保存在扩展 session 中，可重试；下载到磁盘的报告不会随浏览器关闭自动删除。
